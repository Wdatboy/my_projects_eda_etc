## Анализ лояльности пользователей Яндекс Афиши	PostgreSQL · SQLAlchemy · pandas · phik
•  Выгрузил 290 611 заказов из PostgreSQL в pandas через SQLAlchemy: join четырёх таблиц и оконная LAG для интервала между покупками; собрал профили 21 933 пользователей — устройство, регион, оператор и жанр первого заказа, средние чек и число билетов.
•  Привёл выручку из двух валют к рублю по дневному курсу тенге, обнулил отрицательные суммы, проверил хвост по 99-му перцентилю, ужал типы (int32 / int8 / float32); нашёл аномального пользователя с 10 251 заказом при медиане 2 и пересчитал статистики без верхних 5%.
•  Метрики возврата: 61,8% пользователей делают 2 и более заказа, 29% — 5 и более; точка входа почти не влияет — mobile 61,3% против desktop 64,2%, разброс по жанрам 55–64%.
•  Драйвер повторных покупок — размер заказа: сегмент 2–3 билета возвращается в 74,1% случаев против 19,3% у сегмента 5+ билетов (оптовые покупки); phik подтверждает — число билетов 0,41 против 0,13 у региона и 0,04 у жанра.
## Витрина данных маркетплейса и 4 ad-hoc-задачи	PostgreSQL
•  Спроектировал витрину пользователей через цепочку CTE: агрегировал платежи, стоимость и рейтинги на уровне заказа до объединения — исключил дублирование строк (fan-out) при join.
•  Решил 4 задачи: сегментация по числу заказов, топ-15 по среднему чеку через DENSE_RANK, статистика по регионам (рассрочка, промокоды, отмены), когорты по месяцу первого заказа (DATE_TRUNC).
•  Исправил ошибку в данных (рейтинг > 5) и ошибку сортировки в исходном запросе (сумма вместо среднего); NULLIF — защита от деления на ноль.
## Исследовательский анализ рынка общепита Москвы	Python · pandas · phik
